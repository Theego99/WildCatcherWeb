Quick start

基本の流れ

  1. アプリとモデルを準備する

    最新版をインストールし、ライセンスまたはトライアルの状態を確認。必要な検出・分類モデルを準備します。モデルの入手には通信が必要な場合があります。

  2. 入力・出力先を決める

    画像・動画を入力フォルダにまとめ、結果の出力先を指定します。初回は元データをコピーして評価し、出力先に十分な空き容量を確保してください。

  3. 対象と解析設定を選ぶ

    動物・人・車両などの対象、信頼度のしきい値、動画のフレーム間隔を設定。種分類を使う場合は、対応するモデルとライセンスを確認します。

  4. 実行し、処理状況を確認する

    完了したファイルと失敗したファイルを確認します。再開・再試行の機能を使い、エラーが残っていないかログを確認してください。

  5. 目視で確認・修正する

    結果をフィルターで絞り込み、必要に応じて元の画像・動画を確認します。誤った分類ラベルを修正し、確認の履歴を残します。

  6. 出力と保管

    CSV・Excel・JSON・SQLiteなど必要な形式で出力。ProではPDFや対応する外部ツール向け形式も選べます。確認済みの結果と元データを保管してください。

使う前に知っておくこと

オフラインで使えますか？

アプリと必要なモデルの準備後、画像・動画の解析はPC上で行えます。初回のダウンロード、モデルの追加、アプリの更新には通信が必要です。

AIの分類をそのまま使えますか？

撮影条件や対象種によって誤検出・誤分類・見逃しが起こります。実際のデータで設定を評価し、種の同定と報告に使う結果は担当者が確認してください。

解析されないファイルがある場合は？

対応形式、出力先の書き込み権限、空き容量、ライセンスの処理上限を確認します。エラーログと利用バージョンを控えてお問い合わせください。

更新の方法は？

2.1.3以降はアプリ内の「更新」から進められます。2.1.0 / 2.1.1をご利用の場合は、最新版のインストーラーをご利用ください。

MacでVLCは必要ですか？

2.2.0のMac版はネイティブ動画再生に対応しているため、別途VLCをインストールする必要はありません。

コマンドラインでも使えますか？

2.2.0のWindows配布にはCLIを同梱しています。定期処理や大量データへの導入は、必要な設定と出力内容を確認したうえでご相談ください。

お問い合わせの際は

OS・アプリのバージョン、操作内容、表示されたエラーをご記載ください。調査地点や個人情報を含む画像・ログは、送付前に内容をご確認ください。
