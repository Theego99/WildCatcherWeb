Install

はじめて使う方へ。

  1. PCに合うファイルを入手

    Windowsはセットアップ、Macは対応するチップのDMGを選びます。

  2. インストール

    Windowsはインストーラーに従って進めます。MacはDMGを開き、WildCatcher.appを「アプリケーション」にコピーします。

  3. 少量のコピーで試す

    使用許諾を確認して起動。必要なモデルと設定を確認し、まずは元データのコピーで検出・結果確認・出力を試してください。

使い方ガイドへ →

インストール時の確認

OSのセキュリティ確認が表示される場合があります。Mac版はApple Developer IDによる署名・公証が未設定です。管理対象のPCでは、ご利用組織の担当者にインストール可否をご確認ください。

Mac 2.2.0では、動画再生のためにVLCを別途インストールする必要はありません。

すでにご利用中の方

2.1.3以降：アプリ右上の「更新」または「About → 更新の確認」から更新できます。

2.1.0 / 2.1.1：旧版の更新機能に不具合があるため、このページの最新版を一度インストールしてください。

更新前に、ライセンス、モデル、設定、解析結果と元データのバックアップをおすすめします。
