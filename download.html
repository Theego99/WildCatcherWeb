Install

はじめて使う方へ。

  1. PCに合うファイルを入手

    Windowsはセットアップ、Macは対応するチップのDMGを選びます。

  2. インストール

    Windowsはインストーラーに従って進めます。MacはDMGを開き、WildCatcher.appを「アプリケーション」にコピーします。

  3. 少量のコピーで試す

    使用許諾を確認して起動。必要なモデルと設定を確認し、まずは元データのコピーで検出・結果確認・出力を試してください。

使い方ガイドへ →

インストール時の確認

OSのセキュリティ確認が表示される場合があります。Mac版はApple Developer IDによる署名・公証が未設定です。管理対象のPCでは、ご利用組織の担当者にインストール可否をご確認ください。

Mac 2.2.1では、動画再生のためにVLCを別途インストールする必要はありません。

すでにご利用中の方

Windows 2.2.0以降：アプリ内の「更新」から2.2.4へ更新できます。

旧バージョン・手動導入：このページのWindowsインストーラー、またはZIPパッケージをご利用ください。ZIPは「すべて展開」し、フォルダー内のWildCatcher.exeを起動します。_internalフォルダーはアプリと一緒に保管してください。

Mac：Apple Silicon・Intelともに現在の配布版は2.2.1です。対応するDMGまたはZIPをお選びください。

更新前に、ライセンス、モデル、設定、解析結果と元データのバックアップをおすすめします。
